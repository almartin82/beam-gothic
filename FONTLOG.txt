FONTLOG for Beam Gothic
=======================

This file records the development of the Beam Gothic font software. If you modify the fonts,
add your changes here.

Basic font information
----------------------

Beam Gothic is an original caps-only display face drawn after the lettering of the Bethlehem Steel
wordmark, c. 1931-1966. Seven letters (B E H L M S T) are documented in the source material. Every
other glyph is extrapolated from three cutting rules read off those letters: sheared stem ends,
spurred arms, and no curves. The font does not contain the Bethlehem emblem or the wordmark.

Each glyph carries a provenance label in the UFO source (lib key org.fontmachine.provenance):
documented, extrapolated or decided.

The font is generated by a Python glyph program (sources/beam/), written out as a UFO and compiled
with fontmake. Licensed under the SIL Open Font License, Version 1.1 (see OFL.txt).

ChangeLog
---------

2026-11-25 (Andy Martin) Beam Gothic v2.001
- Vendor ID set to ANDY (was the placeholder FMCH). No outline changes.

2026-11-24 (Andy Martin) Beam Gothic v2.000
- Character set extended from 81 codepoints to Google Fonts Latin Core (339 codepoints, 344 glyphs).
- New: the rest of printable ASCII, en dash, double and low quotes, guillemets, ellipsis, bullet,
  middle dot, inverted exclamation and question marks.
- New: 14 combining accents and every accented Latin Core letter, composed through anchors.
- New: AE OE Oslash Eth Dcroat Thorn Lslash Hbar Eng and capital sharp s; currency; copyright,
  registered, trademark, degree; math signs; ordinals, superiors, fractions; section, paragraph,
  daggers, micro; dotted circle.
- Lowercase codepoints are component glyphs of the capitals (no double mapping).
- Comma, semicolon and question mark redrawn.
- Kerning: the 46 hand-picked pairs replaced by class kerning generated from the outlines.
- Features: mark, mkmk, ccmp, locl (Romanian comma-below, dotted i for the Turkic languages).
- Vertical metrics 950/-250 to hold the accents.
- Autohinted with ttfautohint; gasp and meta tables.
- Three style decisions (ampersand, at sign, lowercase) went to the panel; option A picked for each.

2026-11-24 (Andy Martin) Beam Gothic v1.200
- Source of truth rebuilt. The v1.100 build scripts were lost; the drawing program was rewritten
  and reproduces all 54 v1.100 outlines exactly. The build now runs program -> UFO -> fontmake.
- Name table completed: unique ID, full name, PostScript name, copyright, manufacturer, designer,
  description, license and license URL (SIL OFL 1.1).
- OS/2: fsType 0 (was 4, preview-and-print only), Regular bit and Use-Typo-Metrics set, vendor ID,
  PANOSE, Unicode and code page ranges computed from the character map.
- Vertical metrics follow the Google Fonts rule (typo = hhea = 820/-200, win = 820/200).
- Underline position and thickness set. GDEF glyph classes added. prep and gasp tables added.
- Glyphs renamed to production names (A, not uni0041).
- New glyph: quoteleft, the right quote turned 180 degrees. v1.100 mapped both quotes to one glyph.
- Q: tail moved 6 units left, inside the bowl's right edge. Advance corrected from 504 to 520.
- .notdef now draws a box.

2026-11-22 (Andy Martin) Beam Gothic v1.100
- R bowl narrowed to 436 units, R width set to 460. Q tail pulled in. Kerning table added.

2026-11-22 (Andy Martin) Beam Gothic v1.000
- First release, 52 characters.
